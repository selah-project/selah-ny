# Tanakh — kumasulira m'Chichewa (selah-ny)

Ili ndi kumasulira kwa Chichewa kwa Malemba Opatulika a Chihebri
(Tanakh). Vesi lililonse lili ndi fayilo yake, ndipo tokeni iliyonse
yamangidwa ku liwu lake la Chihebri.

**Kalembedwe: zilembo za Chilatini.** Chinenero ndi Chichewa
cholembedwa chovomerezeka (Malawi).

## Chihebri — choyamba

Kumasulira uku kulipo kuti kukutsogolere ku Chihebri — osati kuti
kulowe m'malo mwake. Chimene chimawerengedwa nthawi zonse ndi
Chihebri: zilembo zake, mamvekedwe ake, zizindikiro zake. Mawu a
Chichewa ndi zenera, osati chotsekereza. Pamene ziwiri zisiyana,
choonadi chili m'Chihebri.

## Kapangidwe ka mafayilo

```
<buku>/<chaputala>/<vesi>.json
```

Maina a mabuku m'mafoda alembedwa m'Chingerezi: `genesis/1/1.json`,
`psalms/33/12.json`.

Fayilo iliyonse:

```json
{
  "translation": "vesi lonse lowerengedwa",
  "tokens": [{"surface": "liwu la Chihebri", "gloss": "tanthauzo la Chichewa"}]
}
```

`surface` — **pamwamba**, mbiri ya Chihebri. Si pathu kulembapo;
imachokera ku maziko, ndipo sisinthidwa.

`gloss` — **tanthauzo** la Chichewa la tokeni imeneyi ya Chihebri
yokha. Chiwerengero cha matanthauzo n'chofanana ndi chiwerengero cha
mawu a Chihebri. Nthawi zonse.

`translation` — **kumasulira**: vesi limodzi lowerengedwa m'malo
mwake, kuti liwerengeke momveka.

`marks` — pa tokeni ya ⟨את⟩ yokha: liwu la Chichewa limene
chizindikiro chikuloza.

## Zimene mabulaketi a ngodya ⟨ ⟩ akutanthauza

Mabulaketi a ngodya amagwira ntchito ziwiri, ndipo n'kofunika
kuzisiyanitsa.

**1 · ⟨את⟩ — chizindikiro cha Chihebri chimene sichimasuliridwa.**
M'Chihebri, אֵת ndi liwu laling'ono limene limaima patsogolo pa
chinthu chimene verebu chikuchita. Chichewa chilibe liwu lofanana
nalo, ndipo kumasulira kwambiri kumachisiya mwakachetechete. Ife
timachisunga, chilembedwa monga chalembedwera — ndi gawo la
kapangidwe ka Chihebri. Si cholakwika cha kusindikiza; ndi liwu
limene lili m'malemba. Chizindikiro chili ndi banja: את nthawi zina
imabwera ndi zomamatira (ואת, אתו, אתם) — zonse ndi za banja limodzi.

**2 · ⟨liwu⟩ — Chichewa chimene chilibe m'Chihebri.** Pamene
chiganizo cha Chichewa chikufuna liwu limene mulibe m'Chihebri kuti
chiime, liwu limenelo limaikidwa mkati mwa mabulaketi. Mabulaketi
akuti: *liwu ili linawonjezedwa ndi womasulira; mulibe m'Chihebri.*

**Mkati mwa mabulaketi mulibe chinenero chachilendo.** Mulimo
Chichewa kapena chizindikiro cha Chihebri — palibe chachitatu.

## Dzina

Dzina **silimasuliridwa, limalembedwa monga mwa mamvekedwe ake**.

| Chihebri | apa | chimene chinakanidwa |
|---|---|---|
| יהוה | **Yahwe** | **Yehova**, **Chauta**, **Ambuye**, **Mulungu** m'malo mwa Dzina, **Mphambe**, **Namalenga** |
| אלהים | **Elohim** | **Mulungu** m'malo mwa Dzina |
| אל | **El** | *mulungu* m'malo mwa Dzina |
| אלוה | **Eloha** | — |
| אדני | **Adonayi** | **Ambuye**, **Ambuye Mulungu** |
| שדי | **Shadayi** | **Wamphamvuyonse** yekha |
| יה | **Yah** | — |
| צבאות | **Tsevaoti** | "wa makamu" |
| שאול | **Sheoli** | "gehena", "manda" okha |

**Yehova, Chauta ndi Ambuye akhala m'Mabaibulo a Chichewa kwa nthawi
yaitali.** Komabe, sali apa. Ambuye ndi kumasulira kwa **liwu la
ulemu**, osati kwa Dzina; Yehova ndi mtundu wosakanikirana. Pamene
malemba akuti יהוה, onse awiri amaphimba Dzina. Izi sizikutanthauza
kuti ndi Chichewa choipa — zikutanthauza kuti amaima *m'malo mwa
Dzina, osati Dzina lomwe*. Amene akufuna kumva mwambo adzaupeza
m'Mabaibulo ena a Chichewa. Apa paima chimene chalembedwa.

**Mawu olumikiza ndi galamala.** *wa Yahwe*, *kwa Yahwe*, *ndi
Yahwe*, *mwa Yahwe* — ndi galamala ya Chichewa, osati kusintha kwa
Dzina. Tsinde limakhala lathunthu nthawi zonse. Chosaloledwa ndi
kuthyola tsinde (*Yahw-*, *Yawe*) kapena kusintha chilembo chake
(*Jahwe*).

## Mulungu ndi mbuye odziwika ali ndi malo ovomerezeka

Pamene Chihebri chikunena za milungu ya amitundu kapena za mbuye
amene ali munthu, *mulungu*, *milungu*, *mbuye* amaima moyenera —
kumeneko sikubisa Dzina, ndi kumasulira. **Tokeni ya Chihebri ndiyo
imaweruza, osati liwu la Chichewa lokha.** Mu 1 Mafumu 20:23 anthu
a Aramu akunena za milungu yawo; **milungu** paima moyenera. Mu
Genesis 23:6 Ahiti akunena kwa Avraham kuti *mbuye wathu*; nawonso
paima moyenera.

## Mawu olembedwa chizindikiro

- **khesedi** (חֶסֶד) — chikondi cha pangano chimene sichitha. Osati
  "chifundo" chokha, osati "chikondi" chokha. Palibe liwu limodzi la
  Chichewa limene limachinyamula.
- **Sheoli** (שְׁאוֹל) — malo a akufa, monga Chihebri chikunena.
  Osati "gehena".
- **Mashiya** (מָשִׁיחַ) — **wodzozedwa** — m'mulingo wa Tanakh,
  sakhala "Khristu" konse.
- **Tora** (תּוֹרָה) — chilamulo, chiphunzitso. **ברית** —
  **pangano**.
- **nefeshi**, **ruakhi**, **kavodi** — monga mwa malo awo (moyo
  kapena munthu; mzimu kapena mphepo; ulemerero kapena kulemera) —
  osamangidwa ku liwu limodzi.

Maina a anthu ndi malo amatsatira mtundu wa Chihebri: **Avraham**,
**Moshe**, **Yehoshuwa**, **Shauli**, **Paro**, **Mitsrayimu**,
**Yerushalayimu**.

## Vesi m'kuwala kwake

Vesi lililonse likunena chimene likunena m'malo mwake — timaliwerenga
m'chikhulupiriro cha Chihebri chakuti Elohim ndi mmodzi (Deuteronomo
6:4). Sitikoka chiphunzitso cha pambuyo pake n'kubwerera nacho
m'mbuyo; sitiwerenga mapeto a nkhani pachiyambi pake. Womasulira
amapereka chimene chalembedwa — osapitirira, osachepera.
